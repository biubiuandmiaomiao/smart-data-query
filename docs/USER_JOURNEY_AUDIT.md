# 用户路径验收 · 2026-09-28

本轮实际在独立本地工作区运行浏览器、调用已配置模型、只读查询真实数据库。业务数据库没有写入；验收字段释义未复制到正式工作区。

## 原先存在的问题与本轮处理

| 用户遇到的障碍 | 处理结果 |
| --- | --- |
| 字段配置能保存，但仅靠数据库备注无法判断是否正确 | 自动展示同一行的真实日期、账户和所选数值；先看数据再确认 |
| 字段用途是自动推断，容易被误认为业务已确认 | 明确分开“系统解释、待核对”和“业务已确认”；记录确认时间和字段签名 |
| 只能独立看名称，相似字段难比较 | 勾选最多6项横向比较；模型也能建议相关字段并打开真实比较 |
| 枚举代码仍不知含义 | 可以为实际样例值填写业务名称，并用于候选和样例显示，不改变SQL原值 |
| 指标确认后先看到大段SQL，还要另找执行按钮 | SQL折叠为可选依据；新增“确认并查看结果” |
| 核对字段后容易脱离当前分析 | 从指标预览进入字段确认，保存后回到原分析，保留日期和范围 |
| 示例长期写死日期 | 改为最近7个完整日，并提供不依赖模型的直接选指标入口 |
| account英文被计数规则误判单位 | 范围/时间/技术字段不再自动标注计数单位，增加回归测试 |
| 手机端长确认按钮溢出 | 确认和保存按钮分别整行，弹窗内部可滚动 |

## 已实际验收

- 20项单元/接口测试通过：SQL边界、比率、快照、字段用途、模型引用校验、取样参数化、越界拒绝、确认签名和证据凭据等。
- 原浏览器回归通过：指标新增/编辑、真实模型匹配、点击率计算、筛选候选、刷新恢复、字段用途和跨库拒绝。
- 用户路径回归通过：指标原始值 → 日期重采样/空结果 → 模型解释草稿 → 核对并保存字段 → 回原确认单 → 保存并执行；字段搜索/待确认筛选、同记录对比、代码释义、CSV/SQL下载、历史重命名/复用/删除、390px移动端。
- 浏览器未捕获页面脚本错误。截图保存在 `.data/ui/journey-*.png`。

## 仍有明确边界的功能

这些边界没有包装成已经完成的能力，也不使用模拟数据：

- 系统和模型的白话解释不是业务事实认证。库中不明确的退款范围、归因规则、币种和单位仍须业务人员确认；页面提供真实值和待核对问题作为依据。
- 样例最多20条、候选最多50个来自1000行抽样，不是全量数据或最新数据。可换日期，不能据此证明全表没有某个取值。
- 字段确认表示当前本地工作区的业务核对，不是多人审批或完整版本审计；目前仍是单用户工作台。
- 查询最多展示500组、限制12秒；跨表拼接、多平台统一计算和同比环比不属于当前计算引擎，需预先准备数据库内视图。
- 模型不可用时不能提供自动解释，但直接选指标、真实取样、手工业务说明和计算仍可使用；错误会明确显示。

## 后续优先级

1. 多人使用前增加确认人、修改历史与复核流程，避免不同业务口径互相覆盖。
2. 为重要平台维护经业务确认的单位、归因周期、退款范围和枚举释义；不能仅靠字段名自动生成事实。
3. 对高频慢查询准备数据库内经过核对的日视图，然后再扩展趋势/同比环比。

## 第三轮补充验收

| 交互 | 本轮结果 |
| --- | --- |
| 普通用户选择结束日期 | 包含所选当天，选同一天即可；复用与刷新不漂移 |
| 找常用指标 / 旧分析 | 常用标记持久保存；历史搜索立即过滤 |
| 连续点保存、网络重试 | 前端锁定保存操作；后端相同请求去重，并检查版本 |
| 查到空合计行，不知道是不是0 | 新SQL带参与计算的记录数；无记录单独展示，空比率说明原因 |
| 结果太多，找某个账户 | 在返回结果内搜索、按实际数值排序；可导出可见结果 |
| 查询期间切换页面 | 结果按分析ID保存到页面内存，回来可查看，不串到其他分析 |
| 筛选值多、需要多选 | 候选内搜索、点击选中/取消；选择状态刷新恢复 |
| 原确认单太长、左侧空白 | 字段核对移至左侧；日期、范围与主操作位于右侧 |

24项自动测试通过。新增真实浏览器验收包括同日查询、记录数/无结果、重复保存、常用持久化、结果排序/搜索/导出、查询中切页、历史检索、复用刷新、候选多选和390px页面无溢出。原有模型解析与字段核对路径回归通过。

边界：结果搜索不是数据库全量检索；查询结果刷新后不持久化；旧SQL不额外重写以补记录数。保存请求标识随最近200条分析保留，记录删除或超出保留数量后不再提供该请求的去重。

## 第四轮：用户看数与核对路径

真实验收路径：选择消耗指标 → 按账户查询 → 概览/前10名 → 点击条形 → 原筛选范围下的真实记录 → 字段样例范围核对。另以连续三天按账户查询，验证序列切换、日期趋势、键盘打开溯源、20组分页和手机端。

新增支持：数值概览、可加分组合计、万/亿阅读、原始精度开关、账户排名、日期趋势、结果行溯源、字段样例画像、带日期单位的SVG下载、复制结果摘要。32项自动测试通过，原三套浏览器链路及新增展示验收通过。

计算边界：不把比率/平均值/去重数的分组结果相加；图表中的数值缩写是近似表示；合计为已返回的分组值之和（各组已按原指标精度计算）；原始记录最多20条，按保存的条件从当前库重新读取，不宣称能用样例复算完整结果或还原过去数据库状态。
