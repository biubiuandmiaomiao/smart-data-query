# 智能取数

只连接 `d_root_project_marketing_db`。业务问数、表目录、字段同步、模型上下文、指标保存和查询执行均限制在营销库内。原多库配置已备份并归档，当前界面只保留营销定义。

## 核心设计

| 字段用途 | 例子 | 可以做什么 |
| --- | --- | --- |
| 范围条件 | 账户ID、账户名称、计划、部门、营销目标 | 筛选与分组。即使存为 bigint，也不是可求和数值 |
| 业务时间 | `stat_date`、`report_date` | 日期范围、趋势归属 |
| 数值度量 | 消耗、曝光、点击、成交金额 | 在确认粒度后聚合 |
| 派生比率 | CTR、ROI、CPC、转化率 | 用汇总后的分子与分母重算，不能直接求和或简单平均 |
| 时点数值 | 账户余额 | 需明确时点；当前不提供余额跨期汇总模板 |
| 技术字段 | 主键、采集批次、创建/更新时间、原始JSON | 追溯数据，默认不参与业务计算 |

范围条件与分组独立，例如只看账户 A、按计划统计点击率：账户 A 保存在范围条件中；计划是分组；计算使用 `SUM(点击量) / SUM(曝光量) * 100`。更改分组不会清除账户范围。

## 已有营销指标

- AD投放消耗、曝光量、点击量
- AD点击率、平均点击成本
- ADQ投放消耗、净成交ROI

指标来自真实的AD日投放明细和ADQ账户日报。点击率和ROI计算使用显式高精度十进制分子，分母为零返回NULL。所有模板均可编辑，并可新建营销指标。

## 表粒度与快照

读取真实唯一索引来展示业务粒度。部分名为日报的表仍以采集时间区分多次快照，不能直接叠加。

当业务唯一键含业务日期和采集时间时，可选择“每日最新快照”：按其余业务键与日期分组，使用 `ROW_NUMBER()` 按采集时间倒序只保留一行，再聚合数值。无法识别完整快照键或不含业务日期的表不能直接启用此模板，需要先整理营销库内日表/视图。快照策略不是平台增量计算或数据质量认证；字段用途、粒度及单位仍需业务确认。

## 运行

```powershell
npm start
```

访问 http://localhost:4173/?view=metrics ，字段分类页是 http://localhost:4173/?view=fields 。本分发包不含原设备 `.env`，请按根目录运行说明配置。新环境复制 `.env.example` 后填写连接信息；密码含 `#` 必须用双引号。服务使用固定营销库，不通过页面切换到其他库。

模型在「连接与模型」中配置。分析会读取当前营销指标和相关营销表结构，字段角色同时提供给模型。失败明确报错，不默认回退到其他指标。

## 查询与持久化

- 每次确认冻结指标版本、字段快照、日期、独立范围条件与SQL。
- 可以执行完整确认范围，或明确选择“仅试跑开始日”。营销日报的日期列不能伪装成一小时样本，因此预览采用一个业务日，并显示实际范围。
- 只读事务、字段角色校验、参数绑定、12秒执行上限、最多展示500组并提示截断。支持复制/下载SQL及导出CSV。
- `.data/workspace.json` 保存本地状态；`.data/archives/` 与 `.data/backups/pre-marketing/` 保留调整前数据。
- 当前为单用户、单实例本地工作台，仅监听loopback。共享账号的数据库授权未修改；应用通过固定库名和服务端校验限制可访问范围。
- 跨表拼接、复杂派生指标及跨平台统一口径需要先准备营销库内视图。字段的自动用途分类可以人工维护；已知ID、比率和余额不能伪装为直接加总的度量。

## 主要代码

`server/policy.js`：营销库边界、字段用途与粒度识别。
`server/schema.js`：只读表结构与唯一键。
`server/seeds.js`：营销示例指标。
`server/sql-builder.js`：字段角色校验、独立范围、汇总比率、每日最新快照。
`server/agent.js`：营销范围与数值的模型理解。
`public/app.js`、`public/styles.css`：配置、问数、字段分类与结果页面。

## 面向业务用户的字段核对

普通使用路径：指标字典 → 使用 → 选择日期 → 查看对应原始数据 → 核对或修改字段含义 → 返回确认单 → 确认并查看结果。也可在首页直接用自然语言提问；无需读SQL或数据库备注。

- 营销表与字段：搜索业务名称，筛选待确认字段，勾选最多6个字段，在同一行记录中比较。日期与账户自动作为上下文展示。
- 字段弹窗：实际读取最多20条原始记录，可选日期重查，保留长编号和十进制字符串。没有样例或请求失败时只能保存待确认，不能直接确认。
- 含义解释：常见字段提供基础白话说明；不确定字段明确标为待确认。可调用模型解释业务用途、相似字段区别及需要核对的问题；只发送元数据，不发送样例记录。模型输出须人工核对，不自动发布。
- 代码释义：对样例中的分类代码或编号填写业务名称，之后用于候选选择和样例显示，底层查询仍使用原值；不自动猜测枚举值含义。
- 业务确认：确认记录绑定字段名、类型、数据库备注的签名。同步后定义变化则回到待确认。查看样例的凭据有效期30分钟，服务重启后须重新读取。保存待确认会取消当前确认状态。
- 确认指标时的样例采用当前日期、固定条件和额外范围条件；统计结果仍由原SQL计算。累计快照的原始记录未去重，界面明确提示不能直接相加。
- 备注和SQL保留在可选详情中。普通流程提供业务名称、解释、单位、确认状态与真实值；无须自行理解技术备注。

## 第三轮：查询与操作效率

- 确认单与原始值预览均使用包含结束日的日期选择。选同一天查询一天；保存的定义仍使用半开区间，历史分析复用、刷新不会重复加一天。历史记录中的旧摘要文字保留原样。
- 常用指标：可加入/取消常用、只看常用，标记保存到本地工作区。历史分析支持按名称、业务问题和摘要检索。
- 查询结果增加参与计算的记录数，区别无记录、真实0值、分母为0或数值缺失。老SQL快照没有记录数字段时保留原有结果，记录数显示为未知，不自动重写历史SQL。
- 可在本次返回结果中搜索、排序，支持导出全部返回结果或当前筛选结果。大整数/十进制使用精确比较，不先转换为Number。超过500组时，检索、排序和CSV均只作用于返回的500组，页面明确提示。
- 保存时禁用重复操作，后端按请求标识去重。相同请求重试返回同一记录；指标版本在保存期间变化会拒绝旧定义。
- 查询可在当前标签页内切换导航，结果返回后能重新打开查看。结果仅保存在页面内存，刷新后须重新执行；对话和确认单仍能刷新恢复。
- 筛选候选支持搜索、多选/再次取消。通过候选选择的含逗号值会按原始值保存，不拆成多个筛选值；手工输入多个值仍以逗号分隔。
- 确认页左侧核对字段和业务含义，右侧填写日期与范围；主操作为“确认并查看结果”。

## 第四轮：直观数值与可核对的图表

- 结果概览：无分组时显示本次指标值；分组时显示最高/最低及有效、零值、无法计算组数。金额/次数的SUM、COUNT支持汇总返回分组的数值；比率、平均值、去重数量不跨组相加。合计依据分组查询的既定精度；截断或搜索后的局部合计明确标注。
- 数字阅读：千分位与去除无意义尾零；概览的大数用带“≈”的万/亿缩写。可以切换原始精度。表格、CSV和复制摘要保留原值，图表坐标只用于视觉比较。
- 自动图表：单一分组展示数值最高的前10组；日期结果展示趋势；日期+分组时选择一条分组序列，不把各账户的ROI相加。空值不画为0，日粒度缺日期时不连线。
- 图表和结果行可打开原始记录核对。服务端使用保存时的指标定义、固定筛选、额外范围，再叠加选中分组和日期；周/月范围与原分析边界取交集。试跑只读取开始日。记录从当前数据库读取，不是历史数据快照。
- 字段样例增加数值范围、零值/空值数量；ID/名称展示不同值及样例频次，不做数值求和。画像只描述当前最多20条样例，不代表全表。
- 图表支持SVG下载，文件含指标名称、日期、单位和选中分组；结果摘要可复制（最多前10组并注明范围）。结果表每页20组，有固定表头；搜索、图表与导出作用于全部已返回分组，最多500组。
